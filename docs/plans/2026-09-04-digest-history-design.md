# 周报历史查看设计

## 目标

让已经确认保存的本地周报快照可以回看，验证“动态推荐 → 人工确认 → 可追溯快照”闭环。

## 边界

- 新增只读 `GET /api/digests`，默认返回最近 10 条，最多 20 条。
- 每条历史包含周期、状态、创建时间和已保存的项目快照；不重新计算当前推荐分数。
- UI 在周报页展示历史列表；本切片不发布、删除、发送或修改 `digest_items.decision`。
- 继续复用现有 `digests` / `digest_items` 表，不新增迁移。

## 验收

- 领域层按创建时间倒序返回快照，并正确读取项目、分数、理由和位置。
- API 对无效 limit 使用稳定的 400 响应，对默认请求限制返回数量。
- UI 覆盖无历史空状态和有历史列表状态，不影响现有预览保存流程。
- Vitest、lint、typecheck、build、E2E 通过。
