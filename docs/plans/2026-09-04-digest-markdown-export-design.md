# 周报快照本地 Markdown 导出

## 目标与选择

接续 handoff 中的快照导出切片，让人工确认过的项目清单可以带进笔记工具。比较过历史筛选、本地导出和在线分享：本轮默认推进本地 Markdown 下载；历史筛选后续处理，在线分享涉及外发，暂不接入。

## 数据与边界

- `GET /api/digests/[digestId]/export?scope=active|all` 只读导出指定快照。
- 默认 `active` 包含待定、保留，排除已移除；`all` 包含全部决定，方便复盘。
- 保留原始位置、快照分数和理由；决定取读取时已保存的值。项目名称、链接、描述、下一步行动来自当前收藏库，并明确标注它们不是历史快照字段。
- 不包含私人笔记、兴趣规则和配置快照，不触发推荐重算、数据库写入、发布或第三方请求。
- 导出字符串中转义 Markdown/HTML 特殊字符，仅允许不含凭证的 HTTP(S) 项目链接。文件名由数字快照 ID 与固定 scope 构造。
- 非法参数返回 400，快照不存在返回 404，数据库异常返回不泄露细节的 500；附件响应使用 `private, no-store`。

## 实现与界面

纯格式化逻辑放在 `src/domain/digest/digest-export.ts`，复用已有快照读取函数。新增小型 `DigestExport` 客户端组件，放在历史卡片底部：范围选择、项目数量、下载按钮、生成中、错误可重试和已发起下载提示。导出时或保存决定期间禁止重复操作；没有未移除项目时禁用该范围的下载，仍能改选完整记录。

沿用现有蓝灰配色、4/8/12/16 像素间距、11/12/14 像素文字层级与圆角。`ui-ux-pro-max` 用于状态与键盘可访问性；`frontend-design` 用于卡片底部的克制工具区布局，不为小切片更换字体或全局视觉语言。

## 验证

- 纯函数：过滤、原始顺序、空结果、无分数、特殊字符/危险链接、不泄露笔记。
- Route Handler：400/404/500、附件头、默认范围、全量范围、推荐数据变化不重算快照，导出前后表数据一致。
- Playwright：只用拦截的样例 API，验证下载、scope 切换、空范围、错误重试以及小屏布局，不修改实际数据库或访问第三方。
- 执行 lint、typecheck、Vitest、production build；如浏览器权限受阻，保留真实结果，不把未验证记为通过。
